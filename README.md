# SupperScreen

Windows 电脑控制台与 Android 手机工作台。两端同步待办，手机可启动允许的桌面应用，或直接打开电脑上的 PowerShell。

当前版本为 **0.21.0**。手机顶部统一导航，待办固定在工作台左侧，PowerShell 可直接打开。见 [验收记录](docs/VALIDATION.md)。

## 已实现

- 电脑托盘、可选登录启动、配对二维码、电脑审批、设备权限管理和解除配对。
- 带身份签名和电脑公钥指纹校验的 WSS；USB ADB reverse、可信 LAN、发现、重连、USB 优先和操作去重。
- 电脑支持待办快捷录入、排序、删除及单次撤销。手机获授权后可标记完成，离线时仍可查看缓存。
- Windows 应用选择器、名称与图标、应用允许列表和桌面程序启动。
- CPU、内存、磁盘剩余空间、总音量/静音、基础媒体控制、电脑配置的受控任务。
- 手机左右横屏，应用前台保持常亮。顶部显示电脑名及连接状态，左侧待办独立滚动，右侧展示性能、音量、应用或脚本。
- 经典蓝牙 RFCOMM 承载经过设备认证的 WSS。蓝牙工作台显示待办并支持标记完成，展示 CPU、内存、各盘符已用与总量、磁盘读写和网络收发速率。


## 运行

在仓库的 [Actions](https://github.com/yishipi/SupperScreen/actions) 打开最近一次成功的构建，下载 `windows-x64` 和 `android-debug`，也可以按下方步骤在本地构建。

1. 退出旧版控制台。解压 `artifacts/SupperScreen-0.21.0-win-x64.zip`，运行其中的 `SupperScreen.exe`。保留整个目录。
2. 在手机安装 `artifacts/android/SupperScreen-0.21.0-debug.apk`。用相同签名覆盖安装可保留现有配对和配置。
3. USB：数据线连接手机，开启并授权 USB 调试。电脑默认从 Android SDK 标准目录找 `adb.exe`；可在“连接设置”中修改路径和端口。默认 ADB 服务端口为 **15037**，业务端口为 **8765**。
4. 局域网：在系统设置里让两端加入同一个互通的局域网，也可手动开启 Windows 热点再让手机加入。电脑自动识别可用私有 IPv4 地址，默认端口为 **8766**。原来关闭局域网连接的用户可在「连接设置」重新启用。
5. 在电脑点「连接手机」，用手机 App 扫码。核对两端六位验证码后在电脑确认。按需授予终端和任务权限。
6. 在电脑「应用启动」添加目标程序，为手机授予「启动允许的应用」权限。手机通过蓝牙、USB 或局域网连接后，在主页「应用」点「启动」。

在电脑端「手机与权限」勾选「手机完成待办」后，手机可勾选任务左侧方框完成事项。已完成项显示删除线。任务内容、排序及完成状态可在电脑维护。

Windows Agent 运行时，按 Ctrl + 反引号（数字 1 左边的键）打开待办悬浮窗。可查看待办、勾选完成、输入后回车添加。再次按快捷键或 Esc 关闭。可在「连接设置」修改组合，托盘菜单也有入口。此前保存的自定义快捷键会保留。

手机顶部依次为电脑名、主页、PowerShell、性能、音量、应用、脚本、截屏、连接状态、设置。连接状态和设置固定靠右。主页默认显示性能，点击性能、音量、应用或脚本只切换右侧内容。手机按 USB、局域网、蓝牙的顺序自动选用已连通的链路。

添加框下方可分别设置「文字色」和「背景色」，支持预设、自定义 #RRGGBB 和恢复默认。两端优先显示自定义背景，旧强调色显示为浅色底。每条待办的「编辑」可同时修改标题和两种颜色；托盘快速添加同样支持。颜色同步到手机；旧数据自动迁移并保留原有颜色。

手机磁盘列表超出区域时可单独竖向滚动，CPU、内存和吞吐面板保持固定。电脑端连接状态位于「连接设置」，ADB 路径、端口和序列号可在「USB 调试」中展开。

### 手机快捷截屏

在 Windows 的「截屏」页选择保存目录，并在「手机与权限」开启「保存电脑截屏」。手机连接后点顶部「截屏」，电脑会将每个活动显示器保存为一张 PNG。双屏一次保存两张，文件名包含同一时间戳和屏幕编号。手机显示保存张数。支持蓝牙、USB 和 Wi-Fi，截图保存在电脑所选目录。

### 「应用」和「音量」

点击顶部「应用」或「音量」可在右侧操作。蓝牙、USB 和局域网均支持。蓝牙连着 0.18 或更早的电脑端时，按钮按电脑能力禁用。

在电脑「手机与权限」启用「启动允许的应用」和「音量和媒体」后，即可操作对应功能。局域网连接需要电脑开启「允许局域网连接」。

### 局域网与蓝牙配对

手机加入局域网后，使用 SupperScreen 扫描电脑的配对码。已配对的手机通过局域网发现重连。如果当前网络拦截组播，但两端仍可互通，可用新的配对码更新地址。

使用蓝牙时，在系统中打开电脑蓝牙。在手机 App 按提示授予「附近的设备」权限。蓝牙关闭时，可在 App 点「启用蓝牙」，并在 Android 系统弹窗确认。电脑显示「蓝牙已就绪」后生成配对码，手机扫码并在电脑确认。已配对设备会在蓝牙开启且获授权后自动重连。

蓝牙支持待办、性能、应用启动、音量与媒体、脚本、终端和截屏。磁盘 I/O 为全机物理磁盘读写速率。网络吞吐汇总已连接的非回环、非隧道接口。手机全屏时，从系统边缘向内滑动可临时显示系统栏。

### PowerShell 与快捷脚本

1. 在电脑「手机与权限」为已配对手机开启「PowerShell 终端」。手机在顶部点「PowerShell」，连接期间显示加载状态，收到首屏输出后显示终端。点底部「键盘」输入。在输出区上下滑动可查看历史，继续输入会回到最新位置。支持中文输入、ANSI 颜色、光标、Tab、方向键和 Ctrl+C。采用 Windows Terminal 默认黑色配色与等宽字形。优先使用标准目录安装的 PowerShell 7，否则使用系统 Windows PowerShell 5.1；以 Agent 当前用户身份启动，工作目录为用户目录，不加载用户 Profile。
2. 电脑「脚本」→「添加 PowerShell 脚本」，选择本机 `.ps1` 并填写名称。在「手机与权限」开启「运行电脑配置的任务」，读取权限随之开启。手机在顶部点「脚本」，再点运行，无参数脚本无需填写 JSON；可查看状态、日志及取消运行。高级参数模板在电脑「脚本 → 高级任务」配置。脚本遵循本机 PowerShell 执行策略。
3. 终端和脚本均支持 USB、Wi-Fi 与蓝牙。终端关闭、撤权、解除配对、电脑暂停控制或最后一条认证链路断开时结束对应终端进程。切换链路时若仍有认证链路，会保留该终端。脚本通过原有任务队列执行，运行请求去重，最多四项并行。
4. 终端仅在内存保留最近 256 KiB 输出，手机最多 2,000 行回滚；命令输入和完整终端输出不写数据库或诊断。快捷脚本仍使用有限任务结果保存机制。

### Android 无线 ADB 调试

Android 11 及以上版本可在两端互通的 WLAN 上使用系统「无线调试」。安装或调试 APK 时，可以通过 Android Studio 扫码配对。SupperScreen 的 LAN 连接使用独立配对流程。

## 构建与检查

环境：Windows 11 x64、.NET SDK 10.0.401 或兼容版本；Android SDK 36、Build Tools 36.0.0、JDK 21（本机也验证了 JDK 25）、Gradle Wrapper 9.3.1、AGP 9.1.1。

```powershell
# 设置 JAVA_HOME 与 ANDROID_HOME，或在 src/android/local.properties 指定 sdk.dir。
./tools/Build.ps1
# 只构建电脑端
./tools/Build.ps1 -SkipAndroid
```

```powershell
dotnet test tests/MagicCompanion.Tests/MagicCompanion.Tests.csproj
dotnet run --project tests/MagicCompanion.PlatformChecks -c Release
cd src/android
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```


## 数据与工程

Windows 数据位于当前用户 `%LOCALAPPDATA%/MagicCompanion`。待办、允许应用和设备授权存 SQLite，电脑私钥由 DPAPI 保护。Android 用应用私有 SQLite 缓存待办、SharedPreferences 保存布局、Android Keystore 保存设备私钥，并排除系统备份和迁移。

`src/core` 为协议、配对、SQLite 和服务；`src/windows` 为 WPF/Windows 平台；`src/android` 为 Kotlin/Compose 客户端；`shared/protocol` 为 JSON Schema 和两端共用的签名向量；`tests` 为真实存储、TLS 集成、受控任务和真实命令行验证；`docs` 为需求及验收记录。

快捷脚本只在电脑配置。快捷脚本使用固定程序、参数数组、工作目录、超时和允许参数模式；另提供独立授权的 PowerShell 终端。任务输出只作为受控状态数据保留有限内容，不写诊断日志。示例及协议见 [docs/PROTOCOL-IMPLEMENTED.md](docs/PROTOCOL-IMPLEMENTED.md)。
